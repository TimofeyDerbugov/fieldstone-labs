# Fieldstone Labs — портфолио

Сайт-портфолио студии Fieldstone Labs: сайты, телеграм-боты и ИИ-помощники для бизнеса.

**Сайт:** https://timofeyderbugov.github.io/fieldstone-labs/

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Главная: терминал, работы, услуги и цены, что входит, процесс, инструменты, обо мне, отзывы, вопросы, бриф, контакты |
| `privacy.html` | Политика конфиденциальности |
| `consent.html` | Согласие на обработку персональных данных (152-ФЗ) |
| `cookies.html` | Политика cookie |
| `terms.html` | Пользовательское соглашение |
| `404.html` | Страница «такой страницы нет» |
| `css/style.css` | Все стили |
| `js/main.js` | Печатающийся терминал, бриф (данные никуда не отправляются) |
| `js/cookies.js` | Уведомление о cookie |
| `fonts/` | Inter Tight и JetBrains Mono, лицензия SIL OFL, без Google Fonts |
| `img/cases/` | Скриншоты работ: компьютер (`-d`) и телефон (`-m`) |

## Заглушки: что заменить

Все места, которые нужно заполнить, обёрнуты в `<span class="fill">…</span>` и подсвечены
на сайте жёлтой пунктирной рамкой. Найти все: поиск по `class="fill"`. Когда вписали своё —
убирайте и сам `span`.

**О себе и контакты (index.html)**
- `[Имя Фамилия]` — в первом экране и в «Обо мне»
- `[где и на кого]`, `[сколько лет / с какого года]`, `[Пара фраз о себе…]`
- `[__]` сделанных проектов, `[город]`, `[статус]` (самозанятый или ИП)
- `[@username]` Telegram, `[email]`, `[+7 ___ ___-__-__]`
- `[месяц]` — с какого месяца берёте проекты
- Фото: блок «Фото» в разделе «Обо мне» — замените `<figure class="ph ph--portrait">` на `<img>`

**Цены и сроки (index.html)**
- В таблице услуг: `от [__] дней` и `от [____] ₽` для каждой услуги
- В «Как работаю»: сроки каждого шага `[1 день]`, `[2–5 дней]` и т. д., предоплата `[__]%`
- В вопросах: предоплата, число кругов правок, `[самозанятый / ИП]`, хостинг `[какой]`, `[способы оплаты]`
- В брифе: варианты бюджета `[сумма]` (в `<select id="budget">`), срок ответа `[срок]`

**Инструменты (index.html)**
- `[Python, aiogram]`, `[Swift, SwiftUI]`, `[модели и API…]`, `[+ другой хостинг]`, `[проверить]` — поправьте под свой стек

**Работы (index.html)**
- «Ещё проекты»: ссылки `[ссылка]` для Инфобалла, SnowDesk и TimeLens и скриншоты вместо блоков «Скриншот»
- Четвёртая карточка — под ваш телеграм-бот или ИИ-помощника

**Отзывы (index.html)**
- Только настоящие отзывы клиентов. Пока их нет — раздел можно убрать целиком (`<section id="reviews">`)

**Реквизиты (все страницы)**
- `[ФИО]`, `[самозанятый / ИП]`, `[000000000000]` (ИНН), `[email]`, `[@username]`
- Если подключите свой домен — поменяйте адрес сайта в документах и в `canonical` / `og:` в `index.html`, пути в `404.html`
- В документах реквизиты стоят в таблицах и в подвале — правьте прямо в HTML

## Важно

- Бриф работает для вида: данные никуда не отправляются. Чтобы брифы приходили, нужен сервер или
  Telegram-бот, который принимает форму.
- Работы Apple Mind, Бруклин и Movsisyan — концепты по открытым данным, это подписано на сайте и в соглашении.
