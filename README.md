## Бриф в Telegram: как включить

Сайт статичный, поэтому токен бота нельзя класть в его код — его увидит любой посетитель.
Бриф уходит на маленький бесплатный сервер (Cloudflare Worker), а уже он отправляет сообщение
в Telegram. Пока воркер не подключён, бриф работает вручную: посетитель видит текст брифа,
он копируется, и кнопка «Открыть Telegram» ведёт в чат @timka1895.

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и адрес бота.
   Скопируйте токен вида `123456789:AA...`. Никому его не показывайте.
2. **Ваш chat_id.** Напишите своему боту любое сообщение. Откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":123456789` — это число и есть chat_id.
3. **Воркер.** Зарегистрируйтесь на dash.cloudflare.com (бесплатно) → Workers & Pages → Create →
   Worker → назовите, например, `fieldstone-brief` → Deploy → Edit code. Вставьте содержимое
   `worker/brief-worker.js` вместо кода по умолчанию → Deploy.
4. **Секреты.** В воркере: Settings → Variables and Secrets → добавьте `BOT_TOKEN` (тип Secret, токен бота)
   и `CHAT_ID` (тип Secret, ваш chat_id). Если сайт переедет на свой домен — добавьте
   `ALLOWED_ORIGINS` (тип Text), например `https://fieldstone-labs.ru`.
5. **Сайт.** Скопируйте адрес воркера (вида `https://fieldstone-brief.ИМЯ.workers.dev`) и впишите
   в начало `js/main.js`: `const BRIEF_ENDPOINT = "https://...";`. Залейте изменения.
6. **Проверка.** Отправьте тестовый бриф с сайта — сообщение должно прийти от бота.

Защита: воркер принимает брифы только с адреса сайта, проверяет имя, контакт и галочку согласия,
обрезает слишком длинные поля, а поле-ловушка отсекает простых спам-ботов. Бесплатного тарифа
Cloudflare (100 000 запросов в день) хватит с огромным запасом.

## Заглушки: что заменить

Все места, которые нужно заполнить, обёрнуты в `<span class="fill">…</span>` и подсвечены
на сайте жёлтой пунктирной рамкой. Найти все: поиск по `class="fill"`. Когда вписали своё —
убирайте и сам `span`.

- **Ещё работы** (index.html) — Мангал, Patrik Lunch, Saxap, Зефирок и НоМа Изумруд, скриншоты
  `img/cases/{mg,pl,sx,zf,nm}-home-d.jpg`. Новый сайт — скопируйте карточку `<li class="next__item">`.
- **Инструменты** (index.html) — `[Python, aiogram]`, `[модели и API…]`, `[Swift, SwiftUI]`, `[проверить]`.
- **Фото** в «Обо мне» — замените `<figure class="ph ph--portrait">` на `<img>`.
